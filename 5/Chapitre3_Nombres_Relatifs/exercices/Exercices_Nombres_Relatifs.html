Exercices - Les nombres relatifs

Exercice 1

On donne les nombres suivants : +8 ; −3,5 ; 0 ; 12 ; −0,7 ; −15 ; 4,2 ; −1.

a.Quels sont les nombres positifs ?
b.Quels sont les nombres négatifs ?
c.Quel nombre est à la fois positif et négatif ?
Correction

On donne les nombres suivants : +8 ; −3,5 ; 0 ; 12 ; −0,7 ; −15 ; 4,2 ; −1.

a.Quels sont les nombres positifs ? +8 ; 0 ; 12 ; 4,2
b.Quels sont les nombres négatifs ? −3,5 ; 0 ; −0,7 ; −15 ; −1
c.Quel nombre est à la fois positif et négatif ? 0

Exercice 3

Donner l'opposé de chacun des nombres suivants :

6 → ……
−11 → ……
3,8 → ……
−0,25 → ……
0 → ……
−42 → ……

Les deux nombres sont-ils opposés ?

5 et −5 : ……
−3 et 3 : ……
2,4 et −4,2 : ……
−7 et −7 : ……
0,6 et −0,6 : ……
8 et 8 : ……
Correction

Donner l'opposé de chacun des nombres suivants :

6 → −6
−11 → 11
3,8 → −3,8
−0,25 → 0,25
0 → 0
−42 → 42

Les deux nombres sont-ils opposés ?

5 et −5 : oui
−3 et 3 : oui
2,4 et −4,2 : non
−7 et −7 : non
0,6 et −0,6 : oui
8 et 8 : non

Exercice 6

Compléter avec le signe < ou > :

−4 …… 2
−8 …… −3
5 …… −6
−2,5 …… −2,05
−0,1 …… 0
−7,3 …… −7,03
3,5 …… 3,05
−12 …… −21
Ranger dans l'ordre croissant : 3 ; −5 ; −2,4 ; 0 ; −2,04 ; 1,5 ; −7
Correction

Compléter avec le signe < ou > :

−4 < 2
−8 < −3
5 > −6
−2,5 < −2,05
−0,1 < 0
−7,3 < −7,03
3,5 > 3,05
−12 > −21
Ranger dans l'ordre croissant : 3 ; −5 ; −2,4 ; 0 ; −2,04 ; 1,5 ; −7
−7 < −5 < −2,4 < −2,04 < 0 < 1,5 < 3
