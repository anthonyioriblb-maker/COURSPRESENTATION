EXERCICE 2

b. Ranger dans l'ordre décroissant les nombres suivants :
–1,2 ; –1,02 ; –0,12 ; 0,21 ; –0,2 ; 0,12

EXERCICE 3

La lettre 𝑥 désigne un nombre entier relatif.
Dans chaque cas, préciser toutes les valeurs possibles du nombre 𝑥 :

a. –3,5 < 𝑥 < 1,6
b. –24,1 < 𝑥 < –19,05
Correction
a. –3,5 < 𝑥 < 1,6
𝑥 est un nombre entier relatif donc 𝑥 peut être égal à : –3 ; –2 ; –1 ; 0 ; 1
b. –24,1 < 𝑥 < –19,05
𝑥 est un nombre entier relatif donc 𝑥 peut être égal à :
–24 ; –23 ; –22 ; –21 ; –20

EXERCICE 5

Dans chaque cas, encadrer le nombre par deux entiers relatifs consécutifs.

a. ……. < 6,4 < …….
b. ……. < –2,1 < ……….
c. …….. < –10,6 < ……..
d. …….. < –0,32 < ……….
Correction
a. 6 < 6,4 < 7
b. –3 < –2,1 < –2
c. –11 < –10,6 < –10
d. –1 < –0,32 < 0
