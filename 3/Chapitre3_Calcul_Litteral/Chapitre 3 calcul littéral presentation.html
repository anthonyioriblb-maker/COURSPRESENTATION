Chapitre 3 : Calcul littéral

I. La distributivité

1) La distributivité simple

Propriété : Quels que soient les nombres a, b et k, on a :
k(a + b) = k × a + k × b
k(a − b) = k × a − k × b
Exemples :
A = 5(x + 1)
A = 5 × x + 5 × 1
A = 5x + 5
B = 4(y − 7)
B = 4 × y − 4 × 7
B = 4y − 28
C = 3(2x − t)
C = 3 × 2x − 3 × t
C = 6x − 3t
Propriété : On peut supprimer des parenthèses précédées d'un signe + sans rien changer.
Exemple :
D = 4 + (y + 5x)
D = 4 + y + 5x
Propriété : On peut supprimer des parenthèses précédées d'un signe − en changeant tous les signes des termes à l'intérieur.
Exemple :
E = 4 − (x − 5a)
E = 4 − x + 5a

2) La double distributivité

Propriété : Quels que soient les nombres a, b, c et d :
(a + b)(c + d) = ac + ad + bc + bd
Exemples :
Développer et réduire F.
F = (2x + 3)(y + 7)
F = 2x × y + 2x × 7 + 3 × y + 3 × 7
F = 2xy + 14x + 3y + 21
Développer et réduire G.
G = (2x − 3)(5x + 7)
G = 2x × 5x + 2x × 7 − 3 × 5x − 3 × 7
G = 10x² + 14x − 15x − 21
G = 10x² − x − 21

II. Identité remarquable

Propriété : Quels que soient les nombres a et b :
(a + b)(a − b) = a² − b²
Démonstration :
(a + b)(a − b)
= a × a − a × b + b × a − b × b
= a² − ab + ab − b²
= a² − b²
Exemples :
A = (x − 5)(x + 5)
A = x² − 5²
A = x² − 25
B = (7x − 3)(7x + 3)
B = (7x)² − 3²
B = 49x² − 9
C = (7y + x)(−x + 7y)
C = (7y + x)(7y − x)
C = (7y)² − x²
C = 49y² − x²
D = (5 + 23)(5 − 23)
D = 5² − (23)²
D = 25 − 4 × 3
D = 25 − 12
D = 13

III. Factorisation

Définition : Factoriser une somme (ou une différence) c'est l'écrire sous forme d'un produit. Pour cela on utilise :
• ka + kb = k(a + b)
• ka − kb = k(a − b)
• a² − b² = (a + b)(a − b)
Exemples :
A = 5x + 15
A = 5x + 5 × 3
A = 5(x + 3)
B = (x + 4)(2x − 1) − (x + 4)x
B = (x + 4)[(2x − 1) − x]
B = (x + 4)[2x − 1 − x]
B = (x + 4)(x − 1)
C = x² − 9
C = x² − 3²
C = (x + 3)(x − 3)
D = 9x² − 25
D = (3x)² − 5²
D = (3x + 5)(3x − 5)
